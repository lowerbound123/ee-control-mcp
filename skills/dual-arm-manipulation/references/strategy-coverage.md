# 原技能策略覆盖对照

核对来源：用户提供的 isaac-sim-manipulation 的 SKILL.md、references/harness-contract.md 与 references/arx-x5-field-notes.md。对照的是决策原则与非数值运行语义；不复制历史坐标、速度、夹爪值、测量表、评分数值或特定分类案例。

原策略按适用条件归纳到通用版本。预算策略仅保留为受限仿真的条件分支，当前真机按用户要求不限制执行预算。原技能不推荐默认空中传递；新技能保留放稳换臂优先，并将直接传递标为依赖已验证协调能力的扩展。

## 本技能扩展的适用边界

本次操作经验补充为条件式策略：

| 经验主题 | 技能位置 |
|---|---|
| 跨侧高位失败后比较必要净空与局部可达性，不推断唯一故障原因 | [操作：搬运与任务动作](manipulation-strategy.md#搬运与任务动作) |
| 一臂的失败及时用于复核另一臂计划，保留两臂差异与独立验证 | [协作：左右执行与角色选择](coordination-and-observation.md#左右执行与角色选择) |
| 下降后重新观察对准，不沿用高处像素关系 | [协作：额外观测角度](coordination-and-observation.md#额外观测角度) |
| 主体对准仍需检查突出部分扫掠，碰动后解除接触并重新定位 | [操作：稳定接触方向优先](manipulation-strategy.md#稳定接触方向优先) |
| 夹爪临界误差先看收敛与接触，到位后仍独立试提 | [操作：抓取、接触与稳定持有](manipulation-strategy.md#抓取接触与稳定持有) |

原策略之外的支撑装配、直接传递与实机恢复属于适配扩展，按当前能力和证据执行，不声称原仿真已验证这些操作。固定参数与历史统计不属于本技能动作指南；原文件仍可作为来源查阅，但不能直接重放。
