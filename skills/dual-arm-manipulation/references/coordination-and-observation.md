# 双臂分工、并行、传递与主动观察

## 左右执行与角色选择

遵守用户明确分工；否则以完整位置加姿态可达性、路径、接触稳定性与干涉风险选择执行臂。对象在某一侧时可优先该侧臂，但图像左右不等于机器人左右，跨侧目标也不自动要求同侧臂全程执行。

中央对象优先选择完整路线可达、路径较短且不妨碍另一臂的一侧；必要时把执行臂选择与后续交接一并规划，而不是仅比较当前接近距离。

一臂在跨侧路线出现可达性或跟踪问题后，立即复核另一臂尚未执行的类似路线，把已发现的高度、姿态与净空限制纳入候选方案。复用的是需要核验的假设；两臂可能不对称，不能镜像复制坐标、直接认定同样不可达，或把一臂的恢复成功当作另一臂已验证。

按子任务分配角色：独立执行、主操作、稳定支撑、传递方、接收方或观察。角色可以换，但先确认对象支撑、双方实际状态、旧目标及当前通道；不在未完成接触动作中无条件换臂。

## 双臂并行与协作

| 任务关系 | 执行策略 |
|---|---|
| 两侧对象与路径互不干涉 | 可并行执行，分别核验每臂持有和目标结果 |
| 共享中央通道或目标空间 | 默认串行占用，另一臂先退让并确认实际到位 |
| 一臂稳定支撑、另一臂操作 | 明确保持约束与依赖节点，支撑稳定后再操作，逐步核验相对运动 |
| 一臂执行、另一臂观察 | 执行臂先稳定，观察臂安全取景；通道冲突时先撤出观察臂 |
| 需要转移对象或换臂 | 按支撑转移流程，不把双臂同时跨中心当作交接 |
| 一臂锚定柔性段、另一臂松解或牵引 | 锚定臂须保持夹持与实际位置稳定，锚定失效先恢复再牵引；对拉时两段受力方向须不同 |

线缆、绳索等柔性对象的分工判据与解除互穿顺序见[线绳、柔性物与解除缠绕](flexible-objects.md)：锚定臂的角色与其他任务相同，但“锚定是否仍然有效”本身就是需要持续核验的证据。

并行前检查两臂实际、未到达目标和整段扫掠路径，包含开爪、旋转、腕部、前臂及载物外伸。只有共同坐标标定有效时才量化间距；未经标定不能直接相减两臂局部反馈。净空标准来自当前几何、标定与验证，不能沿用旧场景固定阈值；高度错层不能替代水平/完整几何检查。

末端报告点间距只是筛查，不是夹爪表面或臂身净空的安全保证。规划与停车留出余量；进入净空缓冲区时避免继续相向接近或同时旋转，优先扩大间距。向内转腕、大外伸对象、交叉前臂或姿态不明时增加余量或改串行；批次逐段核验，硬件、夹爪或相机配置变化后重新评估。单次窄间距成功不能证明可以降低门槛。

共享区域进入前，另一臂先撤到本侧停车位，确认实际到位及旧目标不会继续侵入；执行臂完成操作并退出后再换臂。观察臂遵守同样的间距与路径规则。

“同时开始”不保证时间同步、相对位置闭环或协同受力控制。先确认接口能否同步发布、各臂独立速度、先完成一臂的保持方式，以及任一失败对另一臂和队列的影响。工具的 `both`、同一步组合或结构化双臂目标，只在运行契约和任务条件允许时使用。

独立动作可以并行，依赖动作等待先决条件；未知接触、支撑转换和释放使用独立验证节点。短批次仅用于已确认的无接触路径。并行结果按每臂单独判断，一臂成功不代表另一臂成功；若失败使另一臂目标失效或支撑可能变化，先核对双方再恢复。

发生干涉时停止新增靠近动作，核对并安全修正主臂未到达的危险目标及可能继续运动，再让可安全移动的一臂沿已确认路径分段退出，每段看双方实际状态。撤离路线不清时不盲归位或反复升降试探。误差与退让后的恢复可支持干涉判断，但没有接触点证据时不断言只撞了指尖而忽略腕部或臂身。

## 对象传递与换臂

先比较原臂直接完成、放稳后换臂与直接双臂传递。原策略优先采用稳定支撑面的暂存交接，尤其是跨侧超出可达范围、接触不稳或协调能力不明确时。

**支撑面交接：** 选择双方可达、可观察且不妨碍后续路线的暂存区；传递方放稳对象并释放，核验支撑与位姿，沿安全路径退出；接收方重新定位，按其最佳接触方向抓取并验证，随后继续任务。暂存改变对象位置与方向，不能沿用传递前坐标。

**直接传递：** 仅在当前机器人、末端与接口已具备所需协调能力，双方接触区可兼容且支撑转移可观察时考虑；不把它当已验证通用动作模板。先确认各自完整路线、共享区进入顺序、失败回退和可放稳位置。

传递方稳定持有，接收方沿无干涉路径接近可用实体接触部位；接收方形成接触后，验证其足以支撑对象，再受控解除传递方接触。过程中检查对象姿态、滑移、夹爪与臂身干涉，避免两臂对同一对象施加不兼容的位置约束。接收方接管稳定、传递方已脱离，才记为传递完成。证据不足时维持已验证支撑或退回安全暂存，不让双方同时释放，不靠拉扯或增加闭合完成交接。

## 额外观测角度

当主视角和执行腕部不足以确认接触、高度、插入间隙、边沿关系、遮挡后状态或支撑转移时，先补足几何再精准动作。图片放大、原位重复取图或相机名字列表不能替代真正新增证据。

- **稳定执行臂：** 确认已知目标、夹持状态、实际误差及队列。另一臂被选中不代表执行臂不会继续追随旧目标；观察运动也可能推进仿真。
- **选观察位：** 优先已有独立相机或未持物且可安全移动的空闲臂。观察位避开执行臂、对象、障碍与后续动作通道，检查整条臂的扫掠，不为近景穿越载物。
- **联合平移和旋转：** 平移产生视差，分段旋转使画面同时包含关键接触部分、目标边界或支撑面与间隙。每次核验实际到位和可见内容，不能照搬固定位置或角度。
- **多视角比对：** 主视角辅助水平关系，斜侧视辅助高度、近远、外伸和接触。核对场景身份、相机身份与采样时间；实机独立相机不默认同步曝光。矛盾先排查遮挡、视差、时序和工具偏移。
- **观察—微调—再观察：** 观察臂停稳且通道清楚时，执行臂单独做有明确假设的小修正。证据足以确认接触或释放条件后才继续；姿态改变、滑移或关键处再次遮挡时重新取景。
- **下降后重新对准：** 高处图像用于粗定位；接近使相机深度、视差或手指投影关系明显改变时，在接触前重新观察并小幅修正。高处看似居中不证明近处对准，高处的像素偏移或局部映射不能直接用于低处；接触中心不清时补侧视。
- **观察结束退让：** 后续扫掠会经过观察位时先退出并核验；能安全保留且继续有用时保持该位，不为每张图往返归位。

没有空闲臂、额外相机或无干涉观察位时，改动作方案或报告证据不足，不盲操作。观察臂不可达或反复取景无信息增益时停止加码。腕部相机随腕姿变化，不能假设始终看不见或始终朝向某世界方向。

将取景与退出路线纳入计划，当前真机不限制观察预算。仅在受限仿真中，预算不足以兼顾精准观察和安全收尾时暂停该动作，而不是跳过证据。视角补充应在预计需要精准操作前安排，不必等碰撞或失败才执行。支持同步观察的仿真核对同一场景和观察身份；实机按各相机采样时间检查一致性，不强行套用同步假设。
