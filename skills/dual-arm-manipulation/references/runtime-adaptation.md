# 运行接口适配

本技能的操作策略与任务无关，执行语法与控制语义须适配实际服务。先发现工具及 schema；有 `props`/`state` 时读取能力、配置和观察。以下接口名用于识别已有 adapter，不要求其他机器人实现相同工具。

## 实机与仿真

| 项目 | 适配方式 |
|---|---|
| 目标身份 | 实机确认机器人/服务；仿真有 session/episode 时绑定本轮并逐步核对边界 |
| 状态与图像 | 查连接、就绪、反馈年龄、相机身份/时间/序号及缺失原因；实际打开图像 |
| 数值参数 | 坐标、夹爪、限位、容差、步长、速度、发布周期与超时全部从当前配置和标定获取 |
| 进度 | 插值、跟踪、队列、任务判据分别核验，不能互相替代 |
| 执行预算 | 当前真机不设预算限制；仅明确受限的仿真按其真实限制管理 |
| 结束 | 实机按要求安全放物/退让/归位；仿真只结束获准 episode，结束不等于评分或成功 |

实机 ROS 环境与驱动版本、通信域、消息包保持匹配，使用项目所需的独立运行环境。连接或观察不应自动发送动作。遵守用户关于启动、重启和控制范围的要求，不通过改预算、换动作模式、重启或重置场景完成原任务。

当前真机不设置命令数、动作数或任务运行时间预算，不因预算暂停、跳过观察或结束任务。通信等待超时、反馈新鲜度和控制器单动作失败判定属于运行契约，不是执行预算。

## 能力发现与证据边界

优先使用已连接的 MCP。读取任务指令、机器人与动作类型、相机、方向映射、到位条件、停止规则及结束能力，保存双臂初始实际姿态和夹爪状态。确认 props 与 state 的场景身份一致、连接就绪且无未确认动作；未拿到可用图像或未确认目标场景时不动作。

运行工具文档、当前配置、实际反馈和图像优先于旧日志与笔记。区分当前代码事实、特定执行观察和未验证推断；不能把局部成功包装为完整轨迹，也不能仅凭事件先后断言失败的唯一原因。需要查代码时核对实际加载版本与本地修改，不只看 Git HEAD；存在抓取方向配置字段不证明执行器会自动消费它或修正姿态。

评估模型中是否包含对象、容器、另一臂与真实支撑面，区分场景模型中心、几何顶面、规划器接触面和实际标定。模型名称或配置位置不证明接触平面已知；没纳入规划的障碍依然会接触。

## 坐标、工具与方向

辨识平移所在坐标系、姿态表示/单位、旋转作用顺序、工具报告点与接触中心、各臂坐标关系及夹爪反馈转换。home 偏移坐标不能当世界绝对高度；坐标为负不直接说明穿透支撑面。未经标定的像素不直接换算为实际距离。姿态误差使用相应表示的几何距离；四元数正负表示同一姿态，不能把分量差直接当旋转角。

`forward/left/up` 等词对应轴和符号以运行 `motion_deltas` 为准，不以图像方向猜。必要且已有授权时，在净空处用小幅单轴动作核验，再对照前后反馈/图像。旋转可能在工具局部轴，组合通常不能按固定世界轴推断；分步旋转和同子句组合须分别确认。

本项目 ee-control-mcp 的平移为基座轴，旋转为工具局部旋转向量复合；同一 `&` 子句先求和旋转向量再应用。原仿真 adapter 的 `&` 可逐词复合。不要在不同接口间直接迁移组合的顺序预测。

平移按服务报告的轴作用，不额外按腕部姿态旋转基座平移增量。组合覆盖值可能作用于每个分量，不能假定能分别指定各轴幅度；不明确时拆开操作。局部像素拟合仅可在匹配相机、深度、姿态和邻近标定区域内作初值，再用反馈与图像修正；不能外推为整场景定位、深度或接触中心标定。

## 工具、并行与夹爪

本项目提供 `props`、`state`、`send_command`、`move_eef`、`move_joints`。字符命令的左右选择器、`both`、同臂组合、同一步双臂及顺序列表，以 schema 和解析器为准；原仿真可能另有 `finish_episode`。未发现的别名不猜用，绝对目标按当前工具 schema 构造。

读取实际 slow/medium/fast 或其他速度配置，明确它限制的是步长、周期、速度还是动作预算。均匀插值与 ramp 模型不同；插值完成后仍需反馈到位验证。位置、旋转、关节和夹爪容差均以配置为准，重复新反馈确认才有意义。

分别检查位置和旋转误差；有的 warning 只覆盖明显平移不足，纯旋转或部分跟随失败可能不报警。评测通过容差不等于推荐操作误差。动作、命令和物理子步是不同计数，不能据模拟步时长推断 HTTP 墙钟耗时。

夹爪可能使用归一化开度或原生角度，打开/闭合的数值方向不固定；读取转换关系，未指定时保持已有状态的行为也要确认。反馈/电流/力的单位分别解释，未标定电流不能称接触力。

## 队列、目标与恢复

明确所有客户端是否共用队列、相对动作从目标还是实测累加、模式切换的参考来源、超时和失败是否清目标、驱动是否仍保持最后目标。提交后跟踪该批身份及终态，不继续在未知动作后堆纠正指令。

`wait` 超时不是取消，`clear_queue` 可能只清未执行项而不能中止活动动作；先查实际契约，不把它当急停。HTTP 结果未知时先只读确认，动作和结束请求都不盲重发。

区分整批语法拒绝、限位拒绝、IK 不跟随、等待超时和执行失败，不能假设它们都推进目标或都保留旧目标。等待返回或队列排空不保证姿态到位；逐臂检查目标误差和图像。复位通常只改选定臂，但另一臂仍可能追随旧目标或被接触推动，双方状态都要检查。

本项目正常相对运动从已有目标累加，首次控制或切换模式用新鲜反馈建立姿态参考；执行失败/反馈过期取消待执行项并清全部内部目标参考。清参考不撤销驱动已收到的最后目标。终态失败、队列空且反馈新鲜后，无参考的单独夹爪指令会使用关节保持模式，以当前实际关节保持姿态；下一条 EEF 动作重新取反馈参考。使用前核验当前保持姿态与接触安全。

仿真 adapter 失败可能留下尚未到达的目标，后续动作继续累积或让其追上；不能把实机清参考规则套用过去。恢复先看实际/目标/误差与对象支撑，归位可能同时重置夹爪且路径未避碰，持物不盲调用。

原仿真 home 恢复选定臂的 episode 初始姿态与夹爪；本项目实机 home 使用配置的关节基准和夹爪状态。分别核对，不把“初始位置”“关节基准”“接触中心”或“安全停车位”当同一概念；到位以实际反馈确认，不能只看复位目标已写入。

## 图像时序与边界

保存返回的原始图像字节，避免无必要颜色转换。按 metadata 匹配相机，不能靠请求顺序猜缺失图像的位置。记录各相机的实际采样时间/序号与观察年龄，命令后取更新并晚于关键动作的图像；独立相机不默认同序号即同步。

仿真读状态可能不推进物理，重复同图不证明释放后已经稳定；需要合法安全动作推进时同时考虑预算。实机使用当前采样与实际静止状态确认。图像显示链路有问题时，用与当前鉴权/会话/传输匹配的只读客户端落盘再查看，不用不兼容助手绕过连接语义。

核验全局视角与执行腕部视角，必要时补充观察腕部。图像块不可见时，在确实能访问同一服务的环境中只读取图并实际打开输出；不同工具进程的 localhost 可能属于不同机器，某个客户端连接失败不证明服务宕机。取图助手仅观察，不发送、重试动作或结束任务，并遵守原授权。

有 session/episode 时，超时、重连、长批次及任务边界后重新核对身份；旧入队响应不能授权下一场景动作。只在当前轮且服务允许、用户授权时结束；边界变化即停止，不对新轮补发复位/结束。统计成功、阶段评分和物理完成分别报告。

保存授权的轮次范围，每次发运动或结束指令前用最新观察核对绑定；新场景的观察序号可能重新起计，序号增大不能单独证明属于原场景。入队响应的身份与等待后的结果可能来自不同时间，必要时再读新状态。可用前后身份读取包围取图检测读取期间的切换，但只读一致性检查不是后续动作的原子执行锁。

需要结束获准仿真轮时，先确认任务判据、实际复位、当前身份和空队列，再使用服务允许的结束调用并如实填写原因。只要求当前轮时优先不等待下一轮，确认请求已接受后停止；结束等待可能返回新轮且丢弃旧排队动作，不保证评分、对象完成或归位。超时先核验身份与结果，原轮自动结束后不再为形式上的收尾结束新轮。

## 仿真预算策略

仅用于服务明确实施执行预算的仿真；当前真机不启用这一分支。分别记录命令与动作的已用和剩余资源，命令额度有余额、停止模式按命令计数或某个上限为空，不取消任务本身的动作上限。

按实际速度、距离、姿态变化估计动作成本并用已观测成本修正。组合动作考虑耗时较长维度与跟踪、稳定过程；顺序批次累加成本，卡滞按可能耗尽单动作额度预留。不受速率限制的维度不硬套步长估算。只读观察和离线思考不推进该原仿真 adapter 的动作预算。

预留主动观察、复杂交接、安全释放、退让、双臂复位、复位未到位后的恢复及结束调用空间；每完成对象或发生失败后重算。大旋转和复位可能超出单动作额度，应分段核验，不能依赖后续夹爪动作追上。剩余额度只够收尾时不启动新对象，不能只看命令余额等到自动切换场景才发现动作已耗尽。
